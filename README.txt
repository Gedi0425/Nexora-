NEXORA MOBILE PROFILE WEBSITE
=============================
This update follows the newly supplied phone UI reference more closely:
- Dark, black and gold mobile-first profile layout
- NEXORA hero banner and round monogram profile logo
- WhatsApp, Telegram, Instagram, Facebook, TikTok and YouTube icons
- Save Contact button (downloads contact.vcf)
- Four compact service cards
- Embedded map for Adama with Open in Maps link
- Digital future banner, About/services details, contact section

There is intentionally NO bottom Home / Services / About / Portfolio / More navigation bar.

To use in Acode:
1. Extract the ZIP.
2. Open the extracted folder in Acode.
3. Open index.html and Preview.
4. Keep contact.vcf beside index.html so Save Contact can download it.
5. Internet is needed for the workspace images and map.

Before publishing:
- Replace +251900000000 / 251900000000 with your actual business number.
- Replace the sample social profile links and email.
- Replace https://example.com inside contact.vcf with your actual website URL.
- Publish the files to a host such as GitHub Pages, Netlify or Vercel to get a public URL.
